# پورتفولیوی جاهد عالمیار | Jahid Alamyar Portfolio

## اجرا
1. فایل ZIP را استخراج (Extract) کنید.
2. `index.html` را با Chrome، Edge یا Firefox باز کنید.
3. سایت آفلاین اجرا می‌شود؛ تصویر و CSS و JavaScript داخل همین فولدر هستند.

## امکانات
- فارسی/انگلیسی با تغییر کامل جهت RTL/LTR
- حالت تاریک/روشن، ذخیره تنظیمات زبان/تم
- واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- انیمیشن‌های CSS و Reveal هنگام اسکرول
- انتخاب فونت در نوار بالا: Vazirmatn، Tahoma، Arial، System
- دکمه `＋` برای بارگذاری فونت شخصی TTF/OTF/WOFF/WOFF2 در مرورگر (در همان نشست)
- فرم تماس با بررسی فیلدها؛ پیام را در برنامه ایمیل کاربر باز می‌کند (mailto)
- لینک GitHub مطابق لینک داده‌شده (github.com)

## ضروری: تنظیم ایمیل و لینک GitHub
فایل `script.js` را با VS Code یا Notepad باز کنید. در ابتدای فایل این تنظیمات قرار دارد:

```js
const CONTACT_EMAIL = ""; // ایمیل واقعی خود را اینجا وارد کنید
const GITHUB_URL = "https://github.com/"; // آدرس پروفایل واقعی GitHub
```

- مقدار `CONTACT_EMAIL` را با ایمیل واقعی جایگزین کنید؛ بدون ایمیل، فرم مقصد ندارد.
- برای لینک GitHub، لینک عمومی پروفایل‌تان را وارد کنید، مثلاً `https://github.com/USERNAME` (USERNAME را با نام کاربری خودتان جایگزین کنید).
- فرم تماس از `mailto:` استفاده می‌کند، بنابراین برنامه ایمیل/handler در سیستم یا مرورگر باید تنظیم باشد. فرم به تنهایی پیام را به سرور ارسال نمی‌کند. برای ارسال مستقیم سروری باید بک‌اند/سرویس فرم اضافه شود.

## فونت‌ها
- برای ظاهر پیشنهادی فارسی، **Vazirmatn** انتخاب خوبی است. فونت باید در سیستم نصب باشد یا فایل فونت را از دکمه `＋` در سایت انتخاب کنید.
- برای استفاده آفلاین دائمی و یک فونت embed شده: فونت قانونی TTF/WOFF2 را در پوشه پروژه قرار دهید و در `style.css` یک `@font-face` اضافه کنید.
- منبع رسمی Vazirmatn: https://github.com/rastikerdar/vazirmatn
- اگر فونت جدید را انتخاب کنید با دکمه انتخاب فونت، سایت آن را برای همان نشست مرورگر فعال می‌کند.

## یادداشت
پروژه‌ها فعلاً به GitHub عمومی لینک شده‌اند چون URL ریپازیتوری‌های واقعی مشخص نشده است. ایمیل، لینک پروفایل GitHub، لینک شبکه‌ها و URL پروژه‌ها را پس از آماده شدن با لینک واقعی عوض کنید.
